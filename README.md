# 🎓 Platforma për Ligjërata Online

Platformë universitare për ligjërata online me video streaming.

## Struktura
- `backend/` - API dhe logjika e serverit
- `frontend-web/` - Aplikacioni web
- `frontend-mobile/` - Aplikacioni mobil
- `ai-service/` - Shërbime AI (transkriptim, kërkim)
- `docs/` - Dokumentacioni

## Teknologjitë
- Backend: Node.js + Express + PostgreSQL
- Storage: AWS S3
- Encoding: FFmpeg / AWS MediaConvert
- CDN: AWS CloudFront
- Frontend: React
