# Platformë për Ligjërata Online

Platformë e plotë për ligjërata online me:

- **Backend:** Node.js + Express + PostgreSQL
- **Frontend Web:** React
- **Frontend Mobile:** React Native
- **AI Service:** Python (FastAPI)

## Struktura

- `backend/` — API
- `frontend-web/` — Faqja web
- `frontend-mobile/` — Aplikacioni mobil
- `ai-service/` — Shërbimi AI
- `docs/` — Dokumentacioni

## Instalimi

```bash
cd backend
npm install
npm run dev
